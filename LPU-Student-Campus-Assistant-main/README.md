# LPU Student Campus Assistant

## Files
- `index.html`: login page and GitHub Pages entry point
- `dashboard.html`: main campus assistant dashboard
- `auth.js`, `script.js`: JavaScript functionality
- `login.css`, `home.css`: page styles
- Image files: campus and university visuals

## Run locally
Open `index.html` in a browser. This is a front-end demo login; it does not authenticate against a real university server.

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload the contents of this folder (not the ZIP itself) to the repository root.
3. Commit the files to the `main` branch.
4. In Settings > Pages, choose Deploy from a branch, select `main` and `/(root)`, then Save.
5. Wait for the Pages deployment and open the published URL.
